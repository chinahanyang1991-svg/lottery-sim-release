## 安装与运行

1. 把 zip 解压到任意目录，得到一个 `乐透模拟\` 文件夹。
2. 双击文件夹里的 `乐透模拟.exe`。

不要把 exe 单独拷出来运行——它依赖同目录下的 `_internal\` 文件夹和数据库文件，
少一个都起不来。整个文件夹可以随意移动或改名，但内部结构不要动。

不需要预先安装 Python，运行环境已经打包在里面。

**系统要求**：64 位 Windows 10 及以上。首次启动会比后续慢一些（要解压运行环境、
做环境自检、建本地库），耐心等到主窗口出现。

## 首次启动会发生什么

- 弹出《用户协议与隐私说明》，同意后才会进入主界面。同意记录存在本机。
- 走一次环境自检，检查运行目录、数据库与依赖是否齐全。
- 在 exe 同目录生成 `lottery.db`（随包已经带了一份含历史开奖数据的库，程序会直接用）。

**一项已知事项**：数据分析组件 pyarrow（arrow.dll）在 Windows 上若于后台线程加载会触发一次访问冲突
（access violation）。本程序已把该组件的加载固定在主线程以规避——启动预热只把文件读进缓存、
不在后台执行导入。这是随包第三方组件的既有问题；个别机器启动时若仍遇到异常，请重试。

## 关于"预测"，需要说清楚

这个程序做的是**号码模拟与统计分析**：频率、遗漏、区间分布、走势图、覆盖组合、
历史回测比对。它可以帮你把号码摊开、避开扎堆、看清历史分布，也可以把过去的
模拟结果与真实开奖逐期对照。

它**不能预测开奖号码**。开奖是独立随机事件，任何算法都不能提高单注中一等奖的
概率。程序里所有"优选""推荐""模型"字样指的都是统计口径下的号码组合方式，
不是对结果的预知。请把它当成一个分析和记录工具，量力而行。

系统诊断页里有一栏「前向验证」，就是拿这件事本身做实测：用已有历史往前推，
再把推的结果与真实开奖逐区对照。截至本版本随包的这份数据，五个玩法的 15 个分区
**全部未超过随机基线**——也就是说程序自己没有声称预测力，你看到的是实测结论，
不是一段声明。
